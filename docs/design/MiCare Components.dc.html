07 — Form controls

Forms are the product, so they get the register treatment too.

One anatomy for every field: caps label above, help text under the label (not under the input, where it gets skipped), a 48px control with a 3.4:1 outline, and error text that replaces nothing — it is added beneath, prefixed with an icon, and referenced by aria-describedby.

Required is marked in words, not with an asterisk — Required in the label row. Optional fields say “Optional”. A 60-year-old filling this in on a bus should never have to hunt for a legend explaining a symbol.

08 — Buttons

Four variants, three sizes, none below 44px.

Square-ish corners (3px), 600 weight, no gradient, no transform on hover — hover darkens the fill, active darkens further. Sizes are 44 / 48 / 56px tall, so “small” is still a legal touch target rather than a decorative chip.

Primary
White on #0D4A45 — 10.1:1.
Secondary
2px border so the outline itself clears 3:1 as a UI boundary.
Ghost
Underlined, because a bare coloured word is not a button to everyone.
Destructive
White on #96301C — 6.4:1. Always behind a confirmation step, never the default in a pair.
Loading & disabled
Loading keeps its width, states what it is doing, and stays focusable so the label is announced.
On surface-deep
Header pair. Focus ring flips to #E8C468 here.

13 — Practitioner result card

Distance is the ranking, so distance is typeset like a fact.

Name first, then Practice, then address; distance sits top-right in tabular figures where the eye lands after the name. Rows are separated by hairlines, not gaps, so a list of eight reads as a register page rather than eight floating objects.

  • --color-text-subtle → #6E6252 — 5.5:1 on surface, 4.9:1 on sand, so it is safe on both.
