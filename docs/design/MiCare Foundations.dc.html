01 — The direction

A reference work, not a landing page.

MiCare should read like a well-set public register: warm paper rather than clinical white, ink-black text, one deep institutional green that earns its authority by being used sparingly. Evidence is typeset, not decorated. Nothing pulses, nothing counts down.

Density is generous by SaaS standards and deliberately so — the average consumer here is sixty, outdoors, one-handed, and possibly reading with a correction they came to us to renew. Base body text is 17px on mobile and 18px on desktop. Nothing functional ships below 16px.

Typeface pairing
Newsreader
Production Type, SIL Open Font Licence. Headings, wordmark, and page titles only. A screen-first text serif with a large x-height and open apertures — editorial warmth without nostalgia.
Public Sans
USWDS, public domain / OFL. All UI, body copy, forms, data. Plainspoken grotesque built for civic legibility; unmistakable 1/l/I and 0/O at small sizes. Both self-host cleanly as variable woff2.
Numerals: tabular everywhere a figure can change — distance, click-throughs, price, dates.

Rules
  • Serif for anything the site says. Sans for anything the site does.
  • Measure caps at 70ch; long-form prose at 66ch.
  • No text below 16px except mono token labels in this document.
  • Caps-label tracking 0.12em; never letterspace lowercase body.
  • One weight jump per hierarchy step — 400 → 600 → 700, no 800 outside the wordmark.

05 — The Verification badge

A record, not a sticker.

The badge behaves like an entry in a register: squared corners, a hairline rule, a hard left edge in the state colour, and — critically — it always cites its source and its date. A marketing sticker asserts; this one testifies. It never uses a gradient, a gloss, a star, or a rosette, and it is never larger than the practitioner's name.

Plaque — profile page

Checked weekly · how Verification works
When no check timestamp exists (data migration, first import), the date line is replaced by the cadence plus a link to the method — never an empty slot, never a fabricated date, and never “recently”. Its own aria-label drops the date entirely: "Verification: verified. General Optical Council 01-31842. Checked weekly against the register."
Used once per profile, directly under the name. Label interpolates the Practitioner's Profession — Verified {profession} — never a hardcoded word. The registration number is the evidence; show it, always.

@layer base {
  /* Root is left alone: 1rem === the user's own browser font-size, so every --text-*
     token renders the px it documents. The responsive step lives on body, not html —
     stepping the root would compound into the whole rem scale. */
  :root { color-scheme: light; }   /* dark mode is out of scope; without this, a dark OS auto-darkens selects, scrollbars and autofill */
  html { background: var(--color-surface); color: var(--color-text); font-family: var(--font-sans); }
  body { font-size: var(--text-base); line-height: var(--text-base--line-height); }            /* 17px */
  @media (width >= 48rem) {
    body { font-size: var(--text-body); line-height: var(--text-body--line-height); }           /* 18px */
  }
  :focus-visible { outline: 3px solid var(--color-focus); outline-offset: 2px; }
  .on-deep :focus-visible { outline-color: var(--color-focus-invert); }
  /* Ring belongs on the visible control, not a visually-hidden input inside it. */
  label:has(input:focus-visible) { outline: 3px solid var(--color-focus); outline-offset: -3px; }
  @media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; } }
}

On dark mode
Skipped for v1, deliberately. Warm paper is doing structural work here — it is what stops the site reading as clinical — and a dark inversion of it either goes muddy brown or loses the warmth entirely, while the four state colours all need re-tuning to hold 4.5:1 on a dark ground. Worth doing properly later; not worth compromising the light palette for now.
